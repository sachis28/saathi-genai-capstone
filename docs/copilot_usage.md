# GitHub Copilot agent mode usage (v2 plan, Day 40)

The syllabus asks for evidence that GitHub Copilot **agent mode** was used, with the prompts and what was accepted or rejected. Fill this in only from real sessions. Don't write entries for work Copilot didn't do.

## How to produce the evidence (about 20 minutes)

1. In VS Code with GitHub Copilot, open Copilot Chat and switch the mode to **Agent**.
2. Open this repo and give it one of the prompts below.
3. Review the diff it proposes. Keep what is correct and reject the rest.
4. Record each session in the log below and take a screenshot of the agent-mode panel (save it under `docs/evidence/copilot/`).

Suggested prompts:
- "Add 5 new prompt-injection attacks in the encoding category to tests/redteam/attacks.yaml and run pytest tests/redteam."
- "Write docstrings and an OpenAPI description for every endpoint in api/app/main.py."
- "Add an xUnit test in dotnet/Saathi.Tests that checks CopilotClientFactory returns the mock client when the app is configured for mock mode."
